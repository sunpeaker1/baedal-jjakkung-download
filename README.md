# Customer Homepage Starter V1

라이더짝꿍 홈페이지에서 검증한 구조를 일반 고객용으로 정리한 시작 템플릿입니다.

## 포함 기능
- 모바일 우선 반응형 홈페이지
- 서비스/상품 카드
- 문의·제휴 접수
- Vercel Blob 영구저장 지원
- 관리자 문의함
- 이메일 알림(Resend)
- 개인정보처리방침 기본 페이지
- robots.txt / sitemap.xml 기본 구조
- 카카오톡 문의 버튼 자리

## 사용 원칙
1. 이 브랜치에는 실제 고객 비밀번호/API Key/문의 데이터 등을 저장하지 않습니다.
2. 고객별 새 저장소로 복사한 뒤 사용합니다.
3. `.env.example`을 참고해 Vercel 환경변수를 설정합니다.
4. 배포 전 `CUSTOMIZE.md`의 플레이스홀더를 모두 교체합니다.
5. 기본값은 검색 차단 상태입니다. 실제 도메인 설정 후 robots/meta를 공개 상태로 바꿉니다.
