Core Features

링크·QR·문자를 열기 전에 점검

🔗

링크 검사

수상한 주소를 붙여넣어 HTTPS, IP 주소 사용, Punycode, 단축 URL, APK 설치 유도 등 기본 위험 신호를 확인합니다.

▦

QR 코드 검사

Google Code Scanner를 이용해 QR 내용을 읽고, 링크라면 바로 열지 않고 먼저 위험 신호 분석을 실행합니다.

💬

문자 검사

의심스러운 문자 내용을 그대로 붙여넣어 스미싱 의심 표현과 포함된 링크를 함께 확인합니다.

↗️

공유받은 텍스트 검사

다른 앱의 공유 기능으로 받은 링크나 문자 텍스트도 안심링크에서 받아 검사할 수 있습니다.

⚠️

점수 + 이유 + 권장행동

위험 신호 점수만 보여주지 않고 어떤 요소가 문제인지와 다음에 무엇을 확인할지 함께 표시합니다.

🕘

최근 검사 기록

최근 검사 결과를 기기 내부에 저장해 이전에 확인한 링크나 문자를 다시 볼 수 있습니다.

How To Use

검사 방법 3가지

🔗 링크 붙여넣기

  1. 문자나 메신저의 주소를 바로 누르지 않습니다.
  2. 주소를 복사해 안심링크의 링크 검사에 붙여넣습니다.
  3. 검사 결과의 위험 신호 점수와 이유를 확인합니다.
  4. 의심되면 링크 대신 해당 기관의 공식 앱·홈페이지를 직접 엽니다.

▦ QR 검사

  1. 안심링크에서 QR 코드 검사를 누릅니다.
  2. QR을 스캔합니다.
  3. 읽은 내용이 링크면 링크 위험 신호를 검사합니다.
  4. 문자 형태의 내용이면 문자 검사 흐름으로 확인합니다.

💬 문자 검사

  1. 의심스러운 문자 내용을 그대로 복사합니다.
  2. 문자 검사에 붙여넣습니다.
  3. 문자 안의 의심 표현과 발견된 링크를 함께 확인합니다.
  4. 발신자를 믿기 어렵다면 공식 전화번호·앱으로 다시 확인합니다.

↗️ 공유해서 검사

  1. 다른 앱에서 의심스러운 텍스트를 선택합니다.
  2. 공유 메뉴에서 안심링크를 선택합니다.
  3. 링크인지 문자 내용인지에 따라 자동으로 검사 화면을 엽니다.
  4. 결과를 확인한 뒤 접속 여부를 직접 결정합니다.

링크를 열거나 앱을 설치하지 말고, 해당 기관의 공식 앱이나 공식 홈페이지에서 직접 다시 확인하는 것이 좋습니다.

🟡 주의 필요

바로 누르지 말고 발신자와 주소가 맞는지 공식 채널을 통해 한 번 더 확인합니다.

🟢 뚜렷한 신호 적음

위험 신호가 적더라도 개인정보나 결제정보를 입력하기 전 주소와 발신자를 다시 확인합니다.

왜 그런 결과인지

결과 아래에 표시되는 구체적인 위험 이유와 권장 행동을 함께 보고 판단합니다.

중요: 안심링크는 100% 안전 판정 앱이 아닙니다. 위험 신호를 사전에 점검하는 보조 도구이며, 결과가 낮다고 해서 해당 사이트나 발신자를 완전히 신뢰해도 된다는 뜻은 아닙니다.
Privacy

필요 이상으로 개인정보를 요구하지 않게

기기 내부 분석 중심

현재 버전의 기본 위험 신호 분석과 최근 기록은 기기 내부 동작을 중심으로 구성합니다.

접근성 권한 없음

안심링크 자체는 링크 검사를 위해 Android 접근성 권한을 요구하는 방식이 아닙니다.

연락처·사진 수집 목적 없음

링크 위험 신호 확인을 위해 사용자 연락처·사진을 수집하는 구조로 만들지 않습니다.

QR 카메라 처리

Google Code Scanner를 사용해 별도의 상시 카메라 권한을 앱이 직접 보유하지 않는 방향으로 구성합니다.

Troubleshooting

검사가 잘 안 될 때

링크가 올바르지 않다고 나와요

주소 앞뒤의 불필요한 문자나 공백을 제거하고 전체 URL을 다시 복사해 검사합니다.

QR을 읽지 못해요

화면 밝기와 QR 크기를 조정하고 흔들리지 않게 다시 스캔합니다. QR이 손상됐거나 내용이 비어 있으면 읽지 못할 수 있습니다.

문자에 링크가 여러 개 있어요

문자 검사 결과에서 발견된 링크 수와 표시된 주소를 확인하고, 어느 하나라도 의심되면 공식 채널에서 다시 확인합니다.

낮은 위험으로 나왔는데 믿어도 돼요?

아니요. 검사 결과는 보조 신호입니다. 개인정보·결제·앱 설치를 요구한다면 주소와 발신자를 별도로 검증해야 합니다.
