Core Features

정비와 비용을 함께 관리

🛠️

소모품 정비주기

엔진오일, 타이어, 브레이크패드, 에어필터, 구동계 등의 교체주기와 남은 거리를 확인합니다.

🧾

교체·정비 기록

교체한 날짜와 당시 주행거리를 기록해 다음 점검 기준으로 사용합니다.

💸

비용 기록

정비비와 기타 바이크 비용을 기록하고 기간별 유지비 흐름을 확인합니다.

📈

유지비 분석

실제 기록한 비용과 주행거리 이력을 기준으로 기간별 비용과 km당 유지비를 확인합니다.

How It Works

자동 주행거리 사용 순서

01바이크 등록

바이크 정보와 현재 계기판 주행거리를 설정합니다.

02자동관리 설정

주행 판별에 사용할 설정을 확인합니다.

03주행거리 누적

실제 주행으로 판단된 거리가 현재 주행거리에 자동 반영됩니다.

04정비시점 확인

자동 누적된 거리 기준으로 각 소모품의 남은 거리를 확인합니다.

실제 계기판과 차이가 생기면 계기판 보정 기능으로 현재 주행거리 기준을 맞추고 이후부터 다시 자동 누적할 수 있습니다.
