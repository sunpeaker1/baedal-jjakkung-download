바이크체크는 배달·퀵 라이더의 주행거리, 소모품 교체주기, 정비기록, 비용과 유지비를 관리하는 독립 Android 앱입니다. 매번 계기판 km를 입력하는 불편을 줄이기 위해 자동 주행거리 관리 기능도 포함합니다.

Automatic Odometer

현재 계기판을 한 번 맞추고 이후는 자동 누적

🏍️ 자동 주행거리 관리

처음 실제 계기판 주행거리를 기준값으로 설정한 뒤 주행으로 판단된 거리를 자동 누적합니다. 엔진오일·타이어·브레이크 등 소모품의 남은 거리 계산도 이 현재 주행거리를 기준으로 이어집니다.

주행 판별

  • 자동관리 설정에서 사용할 주행 판별 조건을 확인합니다.
  • GPS 속도와 설정된 보조 신호를 이용해 실제 주행 여부를 판단합니다.
  • 신호대기나 잠깐 정차는 바로 한 세션을 끝내지 않도록 설계되어 있습니다.

계기판 보정

  • 앱 거리와 실제 계기판이 달라지면 보정 메뉴에서 현재 값을 맞춥니다.
  • 보정은 현재 주행거리 기준을 맞추는 기능이며 과거 정비기록 자체를 지우지 않습니다.
  • 보정 후 새 기준에서 자동 누적을 계속합니다.

First Setup

01바이크 등록

바이크 정보와 필요한 사진을 등록합니다.

02계기판 기준 설정

현재 실제 계기판 주행거리를 정확히 입력합니다.

03자동관리 설정

자동 주행거리 판별에 사용할 설정과 상태를 확인합니다.

04정비주기 입력

내 바이크에 맞는 소모품별 교체주기를 직접 설정합니다.

교체주기는 앱이 임의의 제조사 기준을 넣는 것이 아니라 사용자가 자신의 바이크·부품·정비 기준에 맞춰 설정하는 방식입니다.
Daily Use

평소에는 이렇게 관리

운행 후

  1. 홈에서 자동관리 상태와 오늘 자동 누적거리를 확인합니다.
  2. 현재 총 주행거리가 실제 계기판 흐름과 크게 다르지 않은지 가끔 확인합니다.
  3. 점검 임박 항목이 있는지 홈과 정비관리에서 확인합니다.

소모품을 교체했을 때

  1. 해당 정비항목 상세로 들어갑니다.
  2. 교체기록을 추가하고 날짜·주행거리·비용 등을 확인합니다.
  3. 저장하면 마지막 교체 기준이 새 기록으로 반영되는지 확인합니다.

비용을 썼을 때

  1. 비용기록 추가에서 금액·날짜·분류를 입력합니다.
  2. 필요하면 영수증이나 관련 사진을 함께 남깁니다.
  3. 분석 화면에서 기간별 총비용과 km당 유지비를 확인합니다.

계기판과 차이가 생겼을 때

  1. 일반 주행거리 입력으로 임의 덮어쓰기보다 계기판 보정 메뉴를 사용합니다.
  2. 실제 계기판 값을 입력해 차이를 확인합니다.
  3. 보정 적용 후 새 기준에서 자동 누적을 계속합니다.
Troubleshooting

자동거리·정비 계산이 이상할 때

자동거리가 안 늘어요

자동관리 ON 상태, 위치 권한, GPS 상태와 자동관리 설정에 필요한 주행 판별 조건을 확인합니다.

실제 계기판과 차이가 커요

계기판 보정 기능으로 현재 기준을 맞춥니다. 과거 정비기록을 억지로 수정하지 않고 현재 기준만 바로잡는 방식입니다.

정비 진행률이 안 보여요

현재 계기판 기준, 정비주기, 마지막 교체기록 중 필요한 기준값이 빠져 있지 않은지 확인합니다.

교체했는데 다음 주기가 안 바뀌어요

해당 소모품의 교체기록이 정상 저장됐는지와 교체 당시 주행거리가 현재 기준보다 올바른지 확인합니다.

자동 주행거리는 GPS와 주행 판별 조건을 사용하는 보조 기록입니다. 실제 계기판이 최종 기준이며 필요할 때 보정 기능으로 맞춰 사용합니다.
