배달내비는 쿠팡이츠·배민 지도처럼 배달에 필요한 짧은 경로를 보기 쉽게 보여주면서, 운행 중 지도를 손가락으로 계속 확대·축소하거나 현재 위치를 다시 맞추는 불편을 줄이기 위해 개발 중인 보조 내비 앱입니다. 현재위치 자동 추적, 운행방향 회전, 경로·회전 안내와 후면단속 경고 표시를 더해 일반 내비처럼 사용할 수 있도록 실주행 검증하고 있습니다.

목적핵심 기능사용 흐름화면 보는 법문제 해결다운로드
Purpose

배달할 때 지도를 덜 만지게

배달앱 지도처럼 짧은 경로는 보기 쉽게, 운행 중에는 일반 내비처럼

쿠팡이츠·배민 지도는 배달 경로를 확인하기 좋지만 운행 중에는 손으로 확대·축소하거나 지도를 다시 맞추는 일이 생길 수 있습니다. 배달내비는 배달에 필요한 짧은 경로를 보기 쉽게 유지하면서 현재 위치를 따라가고, 운행 방향에 맞춰 지도를 돌리고, 다음 회전·남은 거리·후면단속 경고를 한 화면에서 확인하는 것을 목표로 합니다.

설치 안내 · 배달내비는 라이더짝꿍 안에 포함된 화면이 아니라 별도로 설치하는 독립 앱입니다. 사용할 때는 라이더짝꿍과 배달내비를 각각 다운로드·설치해야 합니다. 라이더짝꿍의 짝꿍내비는 메인폰↔보조폰 연결과 목적지 전달을 담당하고, 배달내비는 보조폰에서 지도·경로·주행 화면을 표시합니다. 즉, 짝꿍내비=연결·전송, 배달내비=주행 화면으로 역할이 다릅니다.
Core Features

배달 운행에 맞춘 표시 기능

📍

현재위치 자동 추적

GPS 위치를 따라 지도가 이동해 운행 중 현재 위치를 다시 찾는 동작을 줄입니다.

🧭

운행방향 자동 회전

이동 방향과 센서 정보를 바탕으로 지도를 돌려 진행 방향을 화면 위쪽 기준으로 보기 쉽게 합니다.

↪️

다음 회전 안내

상단·중간 안내 영역에서 다음 회전 방향과 거리를 확인할 수 있도록 구성합니다.

📏

남은 거리·진행 정보

목적지까지 남은 거리와 경로 진행 상태를 주행 화면에서 빠르게 확인합니다.

🔎

배달용 지도 확대

골목과 목적지 접근 구간을 보기 쉽도록 실제 휴대폰 화면에서 지도 확대 비율을 계속 조정하고 있습니다.

📷

후면단속 경고 표시

후면단속 구간을 주행 화면에서 알아보기 쉽게 경고해 일반 내비처럼 안전 정보를 함께 확인할 수 있도록 테스트하고 있습니다.

🔗

짝꿍내비 연동

메인폰에서 받은 목적지를 보조폰 배달내비 화면으로 이어주는 연결 구조를 목표로 개발합니다.

개발 중 화면이므로 지도 확대비율·안내 UI·버튼 위치는 실주행 테스트 결과에 따라 달라질 수 있습니다.
How It Works

사용 흐름

01두 앱을 각각 설치

라이더짝꿍과 배달내비는 별도 앱이므로 각각 다운로드·설치합니다.

02메인폰·보조폰 연결

라이더짝꿍에서 메인폰과 보조폰을 페어링하고 연결됨 상태를 확인합니다.

03보조폰에서 배달내비 실행

배달내비의 위치 권한과 GPS 상태를 확인하고 목적지를 전달받을 준비를 합니다. 두 기기의 페어링은 배달내비가 아니라 라이더짝꿍의 짝꿍내비에서 설정합니다.

04목적지 전송·주행 시작

목적지가 전달되면 경로를 확인하고 주행을 시작합니다.

05자동 추적·회전 확인

현재 위치를 따라 지도가 움직이고 운행방향에 맞춰 회전하는지 확인합니다.

06회전·거리·후면단속 확인

주행 중 다음 회전과 남은 거리, 후면단속 경고 표시를 함께 확인합니다.

핵심: 쿠팡이츠·배민 지도처럼 배달 경로를 보기 쉽게 보면서도, 운행 중에는 손으로 계속 확대·축소하지 않고 일반 내비처럼 현재 위치를 따라가며 확인하는 방식입니다.
On The Road

주행 화면에서 볼 것

상단 안내

  • 다음 회전 방향과 남은 거리를 확인합니다.
  • 경로 계산 중에는 로딩·상태 문구를 확인합니다.

지도 중앙

  • 현재위치 표시와 진행 방향을 확인합니다.
  • 지도를 손으로 움직이면 자동 추적 복귀 상태를 확인합니다.

목적지 접근

  • 목적지 표식과 주변 골목 형태를 함께 봅니다.
  • 실제 도로 상황과 배달앱의 목적지 정보를 우선 확인합니다.

후면단속·안전정보

  • 후면단속 경고가 표시되면 주행 화면에서 위치와 경고 구간을 확인합니다.
  • 개발 버전의 안전카메라 정보는 실제 도로 상황과 다를 수 있으므로 도로표지와 제한속도를 항상 우선합니다.
Troubleshooting

이상할 때 먼저 확인

현재 위치가 안 잡혀요

위치 권한과 GPS가 켜져 있는지 확인하고, 실외에서 위치 정확도가 확보될 때까지 잠시 기다립니다.

지도가 진행방향과 달라요

이동 중 GPS 방향이 안정되는지 확인하고 센서 상태에 따라 잠시 지연될 수 있으므로 실제 도로 방향을 함께 확인합니다.

목적지가 안 넘어와요

배달내비보다 먼저 짝꿍내비의 메인폰·보조폰 연결됨 상태와 목적지 전송 여부를 확인합니다.

연결은 됐는데 배달내비가 안 열려요

보조폰에 배달내비가 실제로 설치되어 있는지, 현재 테스트 구성에서 배달내비가 선택되어 있는지 확인합니다. 공개 버전과 개발 버전은 선택 항목이 다를 수 있습니다.

지도 확대가 불편해요

현재 확대 비율은 실주행 조정 중입니다. 목적지 접근 구간에서는 실제 배달앱 지도와 도로 상황도 함께 확인합니다.
