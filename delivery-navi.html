V0.4.5 개발 중실주행 테스트 중

배달길을 보기 편하게.
지도는 운행방향을
따라가게.

배달내비는 배달 운행 중 지도를 손으로 계속 확대하거나 위치를 다시 맞추는 불편을 줄이기 위해 개발 중인 보조 내비 앱입니다. 현재위치 추적, 운행방향 회전, 경로·회전 안내와 짝꿍내비 연결을 중심으로 검증하고 있습니다.

V0.4.5 개발 버전실주행 검증 중
목적핵심 기능사용 흐름화면 보는 법문제 해결
Purpose

배달할 때 지도를 덜 만지게

핵심은 보조폰에서 계속 보기 좋은 지도

현재 위치를 따라가고, 운행 방향에 맞춰 지도를 돌리고, 다음 회전과 남은 거리 같은 정보를 고정된 안내 영역에서 보여주는 것을 목표로 합니다.

Core Features

배달 운행에 맞춘 표시 기능

📍

현재위치 자동 추적

GPS 위치를 따라 지도가 이동해 운행 중 현재 위치를 다시 찾는 동작을 줄입니다.

🧭

운행방향 자동 회전

이동 방향과 센서 정보를 바탕으로 지도를 돌려 진행 방향을 화면 위쪽 기준으로 보기 쉽게 합니다.

↪️

다음 회전 안내

상단·중간 안내 영역에서 다음 회전 방향과 거리를 확인할 수 있도록 구성합니다.

📏

남은 거리·진행 정보

목적지까지 남은 거리와 경로 진행 상태를 주행 화면에서 빠르게 확인합니다.

🔎

배달용 지도 확대

골목과 목적지 접근 구간을 보기 쉽도록 실제 휴대폰 화면에서 지도 확대 비율을 계속 조정하고 있습니다.

🔗

짝꿍내비 연동

메인폰에서 받은 목적지를 보조폰 배달내비 화면으로 이어주는 연결 구조를 목표로 개발합니다.

개발 중 화면이므로 지도 확대비율·안내 UI·버튼 위치는 실주행 테스트 결과에 따라 달라질 수 있습니다.
How It Works

사용 흐름

01보조폰 준비

배달내비를 실행하고 위치 권한과 GPS 상태를 확인합니다.

02목적지 준비

직접 목적지를 입력하거나 짝꿍내비 연동으로 목적지를 전달받습니다.

03길찾기·주행 시작

경로가 표시되면 주행 화면으로 전환해 안내를 확인합니다.

04자동 추적

현재위치와 운행방향을 따라 지도와 안내 정보를 확인합니다.

짝꿍내비 연결을 사용하는 경우에는 먼저 메인폰·보조폰 페어링과 연결됨 상태를 확인한 뒤 배달내비를 선택합니다.
On The Road

주행 화면에서 볼 것

상단 안내

  • 다음 회전 방향과 남은 거리를 확인합니다.
  • 경로 계산 중에는 로딩·상태 문구를 확인합니다.

지도 중앙

  • 현재위치 표시와 진행 방향을 확인합니다.
  • 지도를 손으로 움직이면 자동 추적 복귀 상태를 확인합니다.

목적지 접근

  • 목적지 표식과 주변 골목 형태를 함께 봅니다.
  • 실제 도로 상황과 배달앱의 목적지 정보를 우선 확인합니다.

카메라·안전정보

  • 개발 버전의 안전카메라 기능은 테스트 데이터와 실제 도로 상황이 다를 수 있습니다.
  • 도로표지와 제한속도를 항상 우선합니다.
Troubleshooting

이상할 때 먼저 확인

현재 위치가 안 잡혀요

위치 권한과 GPS가 켜져 있는지 확인하고, 실외에서 위치 정확도가 확보될 때까지 잠시 기다립니다.

지도가 진행방향과 달라요

이동 중 GPS 방향이 안정되는지 확인하고 센서 상태에 따라 잠시 지연될 수 있으므로 실제 도로 방향을 함께 확인합니다.

목적지가 안 넘어와요

배달내비보다 먼저 짝꿍내비의 메인폰·보조폰 연결됨 상태와 목적지 전송 여부를 확인합니다.

지도 확대가 불편해요

현재 확대 비율은 실주행 조정 중입니다. 목적지 접근 구간에서는 실제 배달앱 지도와 도로 상황도 함께 확인합니다.

현재 개발·실주행 검증 중이므로 공개 다운로드는 연결 안정성과 주행 화면 검증이 끝난 뒤 추가합니다.
