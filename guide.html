라이더짝꿍 사용법

처음 설치했다면 위에서 아래 순서대로 보면 됩니다.

1. 처음 설치·권한 설정
  1. 공식 홈페이지에서 라이더짝꿍 APK를 다운로드해 설치합니다.
  2. 앱을 실행하고 안내되는 접근성·위치·알림 등 필요한 권한을 확인합니다.
  3. 자동기록을 사용할 경우 Android 접근성 설정에서 관련 서비스를 켭니다.
  4. 홈으로 돌아와 자동기록 상태와 날짜가 정상 표시되는지 확인합니다.
권한은 사용하는 기능에 따라 필요합니다. 앱이 권한을 요청하지 않았는데 임의로 모든 권한을 켤 필요는 없습니다.
2. 운행 시작·종료
  1. 운행을 시작할 때 홈의 운행시간 기능을 켭니다.
  2. 운행 중 누적시간과 시간당수익을 확인합니다.
  3. 일을 마치면 홈 화면에서 휴대폰의 뒤로가기 버튼을 누릅니다.
  4. 종료를 선택하면 라이더짝꿍 화면이 닫히고 진행 중이던 운행시간도 종료 처리됩니다.
  5. 지금까지의 운행기록은 저장되며 자동기록 서비스는 계속 동작할 수 있습니다.
3. 배달완료 자동기록
  1. 홈에서 자동기록 ON 상태를 확인합니다.
  2. 배달앱에서 배달을 정상 완료합니다.
  3. 라이더짝꿍 홈에서 플랫폼별 수익과 건수가 반영됐는지 확인합니다.
  4. 세부 내역은 운행기록에서 확인합니다.
  5. 누락·오류가 있다면 해당 기록을 확인하고 필요한 수정만 진행합니다.
배민 자동기록 등 일부 기능은 개발·실주행 검증 상태에 따라 공개 버전에서 제한될 수 있습니다.
4. 수익·운행기록 확인
  1. 홈에서 오늘 총수익, 플랫폼별 수익, 총콜수와 시간당수익을 확인합니다.
  2. 운행기록에서 오늘·주간·월간·달력 기준으로 기간을 선택합니다.
  3. 자동기록과 직접 입력한 기타 수입을 함께 확인합니다.
  4. 필요하면 최근 기록 수정·삭제·복원 기능을 사용합니다.
5. 바이크관리 · 주행거리 자동 누적
  1. 바이크관리에서 현재 계기판 주행거리를 처음 한 번 설정합니다.
  2. 이후 운행을 하면 라이더짝꿍 운행거리 기준으로 주행거리가 자동 누적됩니다.
  3. 엔진오일·타이어·브레이크 등 정비주기를 등록합니다.
  4. 누적 주행거리를 기준으로 남은 거리와 점검 시점을 확인합니다.
  5. 실제 계기판과 차이가 있으면 기준 주행거리를 보정합니다.
핵심: 초기 기준만 맞춰두면 매번 km를 직접 입력하지 않아도 정비주기 관리에 사용할 수 있습니다.
6. 100일 목표 챌린지
  1. 100일 목표관리에서 목표금액과 시작 기준을 설정합니다.
  2. 자동기록·직접입력으로 수익이 쌓이면 누적금액에 반영됩니다.
  3. 홈에서 달성률, 남은 금액, 남은 기간을 확인합니다.
  4. 목표를 다시 시작할 때는 안내되는 초기화 기능을 사용합니다.
7. 안전도우미
  1. 운행 전 안전 관련 설정과 위치 권한을 확인합니다.
  2. 단속경고가 표시되면 앱 안내와 실제 도로표지·제한속도를 함께 확인합니다.
  3. 사고·고장 상황에서는 먼저 안전한 장소를 확보하고 공식 긴급서비스를 우선 이용합니다.
  4. 필요하면 사고메모와 사진 등 현장 증빙을 남깁니다.

짝꿍내비 연결 방법

01두 폰 준비

메인폰과 보조폰 모두 라이더짝꿍을 준비합니다.

02역할 선택

메인폰은 전송자, 보조폰은 수신자로 선택합니다.

03QR 1회 페어링

최초 한 번 QR로 두 기기를 연결합니다.

04목적지 전송

두 폰의 연결됨을 확인하고 목적지를 보조폰으로 보냅니다.

네트워크가 바뀌더라도 기존 연결 구조의 자동 재연결을 이용하는 방식입니다. 보조폰 역할이 잘못 선택되어 있으면 연결 문구가 보여도 목적지를 받지 못할 수 있으니 역할부터 확인하세요.

Troubleshooting

설치·사용이 막힐 때

APK가 다운로드되지 않아요
네이버 등 앱 내부 브라우저에서는 APK 다운로드가 제한될 수 있습니다. 주소를 Chrome 또는 Samsung Internet에서 다시 열어 다운로드해 보세요.
설치 버튼이 안 보여요
Android의 출처를 알 수 없는 앱 설치 권한이 필요한 경우가 있습니다. 다운로드에 사용한 브라우저 또는 파일 앱의 설치 허용 여부를 확인하세요.
자동기록이 동작하지 않아요
라이더짝꿍의 자동기록 ON 상태와 Android 접근성 설정을 먼저 확인한 뒤, 실제 완료 기록이 운행기록에 들어왔는지 확인하세요.
짝꿍내비 보조폰이 반응하지 않아요
보조폰이 반드시 보조폰 · 수신자 역할인지 확인하고, 두 기기의 연결됨 상태와 네트워크 상태를 순서대로 확인하세요.
