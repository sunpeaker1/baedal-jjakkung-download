❓ 사용도우미

홈은 확인용, 운행기록은 직접 입력과 수정, 전체 메뉴는 설정과 백업을 담당합니다.

1. 자동기록 시작전체 메뉴 → 자동기록 설정에서 접근성 ON 상태를 확인합니다. 쿠팡 자동기록을 우선 사용하며 배민 자동기록은 현재 개선 보류 상태입니다.
2. 수입 직접 입력하단 운행기록 → ‘＋ 수입 직접 입력’에서 플랫폼·금액·콜수·메모를 저장합니다.
3. 지역판단활동지역과 선호·주의·회피지역을 설정하면 목적지 감지 시 알림으로 구분합니다.
4. 정산·수익 분석수익 분석에서 플랫폼별 수익, 건당·시간당 수익, 정산 맞추기를 확인합니다.
5. 차량관리현재 주행거리와 마지막 정비 km를 기록하면 점검 임박·권장 상태를 자동 계산합니다.
6. 짝꿍내비전체 메뉴 → 짝꿍내비에서 메인폰과 보조폰을 QR로 한 번 연결하고 인터넷으로 목적지를 전송합니다.
7. 백업/복원휴대폰 교체나 재설치 전에 전체 백업파일을 저장하고, 새 기기에서 복원합니다.
