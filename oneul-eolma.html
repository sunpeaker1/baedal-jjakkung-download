🎯

목표금액 관리

목표금액과 기간, 시작 전 누적금액을 기준으로 목표 진행상태를 관리합니다.

기록을 추가하고 날짜별로 확인하며 필요한 경우 상세·수정·삭제할 수 있습니다.

통계·달성률

오늘·주간·월간 흐름, 목표 달성률, 남은 금액, 기록한 날 평균과 최근 수입을 확인합니다.

📅

월별 리포트·데이터 관리

Daily Use

매일 사용하는 흐름

일 시작 전

  1. 홈에서 오늘 필요금액을 확인합니다.
  2. 현재 금액·남은 금액·달성률을 같이 봅니다.
  3. 오늘 쉬는 날이라면 휴무 설정이 반영됐는지 확인합니다.

수입 기록

  1. 기록 메뉴 또는 추가 버튼에서 수입을 기록합니다.
  2. 날짜와 필요한 분류 정보를 확인합니다.
  3. 저장 후 홈의 현재금액과 달성률이 바뀌었는지 확인합니다.

기록 수정

  1. 기록 목록에서 수정할 항목을 선택합니다.
  2. 잘못 입력한 금액이나 내용을 고칩니다.
  3. 수정 후 목표 계산값이 함께 바뀌었는지 확인합니다.

목표 조정

  1. 목표기간이나 금액이 바뀌면 목표 설정을 수정합니다.
  2. 휴무일이 바뀌면 실제 쉬는 요일에 맞춰 다시 설정합니다.
  3. 남은 근무일 기준의 오늘 필요금액을 다시 확인합니다.
오늘번돈는 라이더짝꿍 자동기록 데이터를 공유하지 않는 독립 앱입니다. 앱 안에서 관리하는 기록을 기준으로 목표와 통계를 계산합니다.
Records & Stats

최근 기록

최근 입력한 수입을 홈에서 빠르게 확인하고 기록 메뉴에서 날짜별 내역을 확인합니다.

기간별 통계

오늘·최근 7일·이번 달 등의 수입 흐름을 확인해 목표 달성 속도를 비교합니다.

플랫폼·시간대 정보

현재 UI에서는 기록된 데이터를 플랫폼별·시간대별로 나눠 보는 구성도 포함합니다.

월별 리포트

월 단위로 기록과 수입 흐름을 확인해 기간별 변화와 목표 진행을 살펴봅니다.

Troubleshooting

계산이 예상과 다를 때

오늘 필요금액이 너무 커요

목표 종료일, 남은 금액, 휴무일이 실제 계획과 맞는지 확인합니다. 남은 근무일이 줄면 하루 필요금액은 커집니다.

기록했는데 금액이 이상해요

최근 기록에서 중복 입력이나 잘못된 금액이 있는지 확인하고 해당 기록을 수정합니다.

목표를 다시 잡고 싶어요

기존 기록을 무조건 지우기보다 목표 설정만 먼저 변경해 새 기준으로 계산되는지 확인합니다.

처음 설치한 상태로 다시 시작하고 싶어요

더보기의 데이터 관리에서 초기화를 선택합니다. 확인 후 수입 기록·목표·첫 실행 상태가 삭제되며 삭제 데이터는 복구할 수 없습니다.

V1.14.1은 앱 내부 데이터 초기화 기능까지 포함한 현재 테스트 기준본입니다. 스토어용 정식 서명·배포는 별도 출시 단계에서 진행합니다.
