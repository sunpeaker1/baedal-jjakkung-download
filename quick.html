Core Features

오더를 보는 기준을 미리 정해두기

📍

출발·도착 조건

원하는 출발지·도착지 기준으로 오더를 판단할 수 있도록 필터를 설정합니다.

⭕

반경 설정

내가 볼 범위를 설정해 너무 멀리 떨어진 오더를 줄이는 데 사용합니다.

₩

최소금액

원하는 최소 금액 기준을 설정해 조건에 맞는 오더를 빠르게 구분합니다.

📅

예약 제외

즉시 수행할 오더 중심으로 보고 싶을 때 예약 오더 제외 설정을 사용합니다.

🔁

중복 방지

같은 오더가 반복해서 표시되는 상황을 줄이고, 이미 본 오더를 계속 다시 처리하지 않도록 돕습니다.

📈

금액 상승 재감지

같은 오더라도 금액이 올라 조건이 달라졌다면 다시 확인할 수 있도록 재감지합니다.

처음 사용할 때

01APK 설치

관리자 배포 파일을 설치하고 퀵짝꿍을 실행합니다.

02접근성 설정

오더 화면 확인에 필요한 Android 접근성 설정을 확인합니다.

03필터 설정

출발·도착·반경·최소금액·예약 제외 등 자신의 기준을 정합니다.

04오더 화면 확인

지원되는 퀵 화면에서 조건에 맞는 오더 표시를 확인합니다.

Daily Use

실제 운행 중 사용하는 방법

필터를 너무 넓게 잡지 않기

  • 출발·도착 범위와 반경을 실제 활동지역에 맞춥니다.
  • 오더가 너무 많이 잡히면 반경이나 금액 조건을 좁힙니다.
  • 너무 적게 잡히면 조건을 한 항목씩 완화합니다.

예약·중복 설정 확인

  • 예약 오더를 원치 않으면 예약 제외 상태를 확인합니다.
  • 같은 오더 반복 표시가 많다면 중복 방지 상태를 확인합니다.
  • 금액 상승 후 다시 볼 필요가 있는 오더는 재감지 흐름을 이용합니다.

알림을 보고 최종 판단

  • 퀵짝꿍의 선별 결과는 확인 보조입니다.
  • 실제 출발지·도착지·금액·시간 조건은 원래 퀵앱 화면에서 다시 확인합니다.
  • 최종 수락·취소·수행 결정은 사용자가 직접 합니다.

설정 변경 후

  • 한꺼번에 여러 조건을 바꾸기보다 한 항목씩 바꾸면 어떤 조건이 영향을 주는지 확인하기 쉽습니다.
  • 실제 오더가 많은 시간대에 짧게 확인해 필터를 맞춥니다.
Troubleshooting

오더가 잘 안 잡힐 때

오더가 있는데 감지가 적어요

접근성 설정이 켜져 있는지 확인한 뒤 반경·최소금액·출발·도착 조건이 너무 좁지 않은지 하나씩 확인합니다.

너무 많은 오더가 보여요

활동지역 반경을 줄이거나 최소금액과 출발·도착 조건을 더 구체적으로 설정합니다.

같은 오더가 반복돼요

중복방지 상태를 확인하고, 금액 상승으로 재감지된 오더인지도 함께 확인합니다.

예약 오더가 보여요

예약 제외 설정이 활성화되어 있는지 먼저 확인합니다.

퀵짝꿍은 오더 선택을 돕는 보조 앱입니다. 플랫폼의 실제 오더 정보와 수행 가능 여부를 최종 기준으로 확인하세요.
