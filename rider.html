라이더짝꿍은 배달 라이더가 운행 중 반복해서 확인하고 기록해야 하는 일을 줄이기 위해 만든 메인 운행도우미입니다. 자동기록, 수익분석, 운행기록, 목표관리, 지역판단, 바이크관리, 안전도우미와 짝꿍내비를 한곳에서 사용할 수 있습니다.

앱 구분: 짝꿍내비는 라이더짝꿍 안에 포함된 메인폰↔보조폰 연결 기능입니다. 배달내비는 보조폰에서 지도·경로를 보여주는 별도 독립 앱이므로, 배달내비를 사용할 때는 따로 설치해야 합니다.

Core Features

라이더짝꿍에서 할 수 있는 일

기능 이름만이 아니라 실제 운행에서 어떤 일을 줄여주는지 기준으로 정리했습니다.

🧾

쿠팡이츠 자동기록

쿠팡이츠 배달 완료 수익과 건수를 자동으로 기록해 반복 입력을 줄입니다. 현재 정상 작동 기준으로 보호·운영 중인 기능입니다.

📊

수익·운행 분석

오늘 총수익, 건수, 운행시간, 시간당수익과 기간별 흐름을 확인해 실제 운행 성과를 빠르게 파악합니다.

🎯

100일 목표관리

목표금액과 현재 누적수익을 비교해 달성률, 남은 금액과 남은 기간을 한눈에 확인합니다.

📍

지역판단 · 추천

활동지역과 선호·주의·회피 기준을 활용하는 기능으로 현재 테스트·보완 중입니다. 완성 기능으로 안내하지 않습니다.

🏍️

바이크관리 · 주행거리 자동 누적

처음 현재 주행거리를 설정하면 이후 라이더짝꿍 운행거리를 자동 누적해 매번 km를 직접 입력하지 않고 정비주기를 관리합니다.

🛡️

안전도우미

전방·후면 단속경고, 긴급연락, 사고메모·사진, 위험도로 메모 등 실제 운행 중 필요한 안전 기능을 모아둡니다.

🧭

짝꿍내비

메인폰에서 확인한 목적지를 보조폰으로 보내 길안내를 이어줍니다. 외부 내비를 사용할 수 있고, 개발·테스트 구성에서는 별도 설치한 배달내비와의 연동도 확인 중입니다.

💾

정산·비용·증빙·백업

정산, 주유, 정비, 렌트·리스, 증빙과 데이터 백업까지 운행 외 관리 업무를 한 앱에서 이어서 처리합니다.

How To Use

기능별 사용법

자주 사용하는 기능부터 실제 순서대로 정리했습니다.

🧾 쿠팡이츠 자동기록

  1. 앱에서 자동기록 상태가 ON인지 확인합니다.
  2. Android 접근성 설정에서 필요한 자동기록 서비스를 허용합니다.
  3. 쿠팡이츠 배달을 완료한 뒤 홈의 금액·건수가 정상 반영됐는지 확인합니다.
  4. 잘못 기록된 내용은 운행기록에서 확인·수정합니다.

⏱️ 운행 시작·종료

  1. 운행 시작을 켜고 누적 운행시간을 확인합니다.
  2. 수익이 기록되면 시간당수익 계산에 함께 반영됩니다.
  3. 일을 마칠 때 홈에서 뒤로가기 → 종료를 선택합니다.
  4. 앱 화면과 운행시간은 종료되고 기록은 저장됩니다.

🏍️ 바이크 주행거리 자동 누적

  1. 바이크관리에서 현재 계기판 주행거리를 처음 한 번 설정합니다.
  2. 운행 후 앱의 주행거리가 자동으로 누적되는지 확인합니다.
  3. 엔진오일·타이어·브레이크 등의 정비주기를 설정합니다.
  4. 누적거리 기준으로 남은 거리와 점검 시점을 확인합니다.

🧭 짝꿍내비

  1. 메인폰과 보조폰에서 역할을 각각 선택합니다.
  2. 최초 1회 QR로 페어링합니다.
  3. 두 기기에 연결됨이 표시되는지 확인합니다.
  4. 메인폰의 목적지를 보조폰 내비로 전송해 사용합니다.
  5. 배달내비를 선택해 사용할 경우 보조폰에 배달내비가 별도로 설치되어 있는지도 확인합니다.

🎯 100일 목표

  1. 목표금액과 시작 기준을 설정합니다.
  2. 운행 수익이 누적되면 목표 달성액에 반영됩니다.
  3. 현재 달성률과 남은 금액을 확인합니다.
  4. 필요하면 목표 기준만 초기화해 다시 설정합니다.

🛡️ 안전도우미

  1. 운행 전 단속경고와 필요한 안전 설정을 확인합니다.
  2. 주행 중 앱의 경고와 실제 도로표지·제한속도를 함께 확인합니다.
  3. 사고 시 안전한 곳을 확보하고 공식 긴급서비스를 우선 이용합니다.
  4. 필요하면 사고메모·사진 등 증빙을 남깁니다.

Troubleshooting

문제가 생겼을 때 먼저 확인

쿠팡 자동기록이 안 될 때

자동기록 ON 여부와 접근성 서비스가 켜져 있는지 먼저 확인합니다. 쿠팡이츠 배달 완료 후 바로 반영되지 않으면 운행기록도 함께 확인합니다.

짝꿍내비가 연결되지 않을 때

메인폰·보조폰 역할이 올바른지, 최초 페어링이 완료됐는지, 두 기기에 연결됨이 표시되는지 순서대로 확인합니다.

주행거리가 맞지 않을 때

바이크관리의 현재 기준 주행거리를 확인하고 실제 계기판과 차이가 있다면 보정 기능으로 기준을 맞춘 뒤 다시 누적합니다.

APK 설치가 막힐 때

앱 내부 브라우저에서 다운로드가 제한될 수 있습니다. Chrome 또는 Samsung Internet에서 공식 홈페이지를 열어 다시 시도합니다.
