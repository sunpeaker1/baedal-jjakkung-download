V0.1 · Android

영상복귀 도우미

광고 종료 가능 시 진동으로 알려주고, 사용자가 광고를 직접 닫은 뒤 원래 영상 앱으로 돌아가도록 돕는 보조 앱입니다.

주요 기능
대상 앱 선택돌아갈 영상 앱을 한 번 선택해 저장합니다.
종료 가능 알림광고 종료 가능 상태를 감지하면 진동으로 알려줍니다.
자동 복귀광고를 직접 닫은 뒤 홈 화면으로 빠지면 원래 앱으로 복귀를 시도합니다.
간단한 설정자동복귀 ON/OFF, 접근성 설정, 실행 테스트를 지원합니다.
APK 다운로드
파일명: VideoReturnHelper-v0.1-debug.apk
설치 후 사용 순서
  1. 앱을 설치하고 실행합니다.
  2. 돌아갈 영상 앱을 선택한 뒤 저장합니다.
  3. 접근성 설정에서 영상복귀 도우미를 켭니다.
  4. 직접 광고 종료 후 자동 복귀를 켭니다.
안내
이 앱은 광고의 X/닫기 버튼을 자동으로 누르거나 광고를 자동으로 건너뛰지 않습니다. 광고 종료는 사용자가 직접 해야 하며, 종료 후 원래 영상 화면으로 돌아가는 과정을 보조합니다.
