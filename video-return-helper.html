V0.3 · Android

영상복귀 도우미

진동·음성 알림 없이 조용히 동작합니다. 보상 선택과 광고 종료는 직접 하고, 광고 종료 뒤 홈 화면으로 빠지면 기존 영상 화면으로 자동 복귀합니다.

V0.3 주요 기능
조용한 보상 화면 감지보상 화면을 감지하지만 진동이나 음성 알림을 발생시키지 않습니다.
직접 보상 선택2배 보상 수령은 사용자가 직접 누릅니다.
영상 화면 자동 복귀광고를 직접 닫은 뒤 홈 화면으로 빠지면 기존 영상 앱으로 자동 복귀를 시도합니다.
반복 대기복귀 후 다음 영상에서도 같은 흐름을 계속 감지합니다.
V0.3 APK 다운로드
파일명: VideoReturnHelper-v0.3-debug.apk
사용 순서
  1. 대상 영상 앱을 선택해 저장합니다.
  2. 접근성 설정에서 영상복귀 도우미를 켭니다.
  3. 직접 광고 종료 후 영상 화면 자동 복귀를 켭니다.
  4. 영상 → 보상 화면 → 2배 보상 수령 직접 누름 → 광고 직접 닫기 → 영상 화면 자동 복귀 → 다음 영상 대기 순서로 동작합니다.
안내
진동·음성 알림은 사용하지 않습니다. 보상 수령 버튼이나 광고의 X/닫기 버튼을 자동으로 누르지는 않으며, 보상 선택과 광고 종료는 사용자가 직접 합니다.
