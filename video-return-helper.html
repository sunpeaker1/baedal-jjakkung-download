V0.2 · Android

영상복귀 도우미

보상 화면과 광고 종료 가능 상태를 진동으로 알려주고, 사용자가 직접 광고를 닫은 뒤 기존 영상 화면으로 돌아가도록 돕습니다.

V0.2 주요 기능
보상 화면 감지보상 수령 화면이 나타나면 진동으로 알려줍니다.
광고 종료 알림광고를 닫을 수 있는 상태가 되면 진동으로 알려줍니다.
영상 화면 복귀광고를 직접 닫은 뒤 홈으로 빠질 경우 기존 영상 앱 태스크로 복귀를 시도합니다.
반복 감지한 번 끝나도 다음 영상에서 같은 흐름을 계속 감지합니다.
V0.2 APK 다운로드
파일명: VideoReturnHelper-v0.2-debug.apk
사용 순서
  1. 대상 영상 앱을 선택해 저장합니다.
  2. 접근성 설정에서 영상복귀 도우미를 켭니다.
  3. 직접 광고 종료 후 영상 화면 자동 복귀를 켭니다.
  4. 보상 화면 진동 → 직접 보상 선택 → 광고 종료 가능 진동 → 직접 닫기 → 영상 복귀 흐름으로 사용합니다.
안내
보상 수령 버튼이나 광고의 X/닫기 버튼을 자동으로 누르지는 않습니다. 광고 종료와 보상 선택은 사용자가 직접 해야 하며, 이 앱은 감지·알림·복귀를 보조합니다.
